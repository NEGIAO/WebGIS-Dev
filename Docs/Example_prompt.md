# 🛰️ Agent 任务启动模板（Prompt Template）

> **用途**：新会话开工前，复制下方模板填空后发给 Agent，一次性把「规范约束 + 任务上下文 + 验收标准」交代清楚。
> **与 [`Force_command.md`](Force_command.md) 的分工**：Force_command 规定 **Agent 怎么执行**（是规范本身）；本文件提供 **用户怎么下达**（是使用规范的入口）。本文件不重复规范内容，只做引用。

---

## 📌 通用开场白（每次会话第一句，必带）

```text
开工前请完整阅读 Docs/Force_command.md 并严格遵守。
先声明本次任务等级（L0/L1/L2/L3），再开始分析。
```

> 这一句是让规范生效的唯一开关——本仓库未设置自动加载入口，Agent 不会主动去读该文件。

## ✅ 收尾提醒（Agent 收工时你该看到什么）

对照 [`Force_command.md` 第 7 节 DoD](Force_command.md) 与第 8 节交接块，验收时确认：

| 检查项 | 说明 |
|---|---|
| 任务等级已声明 | 开工第一步就该说 |
| 日志已建 | `Docs/LLM_record/YY-MM/YYYY-MM-DD/YYYY-MM-DD-topic.md` |
| 版本号三处同步 | 根 README 项目简介行 / 版本表首行 / 页脚 |
| CHANGELOG 已追加 | `Docs/Guide/CHANGELOG.md` 顶部 |
| 结构树已同步 | 有文件增删时，对应 `Guide/*-structure.md` |
| 门禁已跑且通过 | `CheckStructureTree.py` + `CheckConfigRegistry.py` |
| 无 Git 写操作 | commit / push 决策权在你 |
| 交接块已输出 | 含「待用户操作」与「遗留风险」 |

> 缺项时直接回一句「按 Force_command 第 7 节补齐 DoD」即可，无需逐条复述。
