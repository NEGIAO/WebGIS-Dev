## 问题分析

### 核心症状
- 英文 UI 下管理员控制台标题/表单/CRUD toast 仍中文
- Chat 导出空对话仍硬编码「暂无可导出的对话内容」；下载文件名含中文

### 根本原因
- `admin.*` 语言包已较全，但 `AdminControlPanel.vue` 未 `useLocale`，模板与脚本仍字面量
- Chat 仅 export 空态 / 文件名漏接

### 受影响模块
- `AdminControlPanel.vue`
- `ChatPanelContent.vue`
- `locales/zh-CN.js` / `en-US.js`（补缺键）

---
