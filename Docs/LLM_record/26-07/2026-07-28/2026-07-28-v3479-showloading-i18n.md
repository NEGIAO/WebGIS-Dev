# V3.4.79 — showLoading 全链路中英文 i18n

> 日期：2026-07-28 20:20  
> 任务等级：L2  
> 版本号：V3.4.79  
> 顺延说明：接 V3.4.78 遗留「路由 / HomeView / 规划器 showLoading 文案键化」

---

## 问题分析

### 核心症状
- 英文界面下全局 Loading 遮罩仍出现中文（鉴权、3D 加载、GIS 导入、流体高度、公交/驾车规划）
- 路由进首页曾硬编码英文 `Loading Map Engine & Assets...`，中文环境也不一致

### 根本原因
- `showLoading(text)` 调用方直接传字面量；`GlobalLoading` 只对**空**默认文案做了 i18n
- 路由守卫无 Vue setup，无法 `useLocale()`，但可直接 `import { translate }`

### 受影响模块
- `router/index.js`、`HomeView.vue`
- `CesiumContainer.vue`、`FluidSimulationPanel.vue`
- `DrivingPlannerPanel.vue`、`BusPlannerPanel.vue`
- `locales/core.js`（首屏键，守卫在懒加载 full pack 前就会触发）

---

## 修改内容

1. **core `loading.*`**：authCheck / mapEngine / cesiumAssets / cesiumOverlay / cesiumScene / cesiumLoadFailed / gisImport / fluidHeights / drivingRoute / busRoute（zh+en）
2. **调用点**：一律 `showLoading(t('loading.xxx'))`；HomeView 叠加层与 Cesium 失败 toast 同步键化
3. **非 setup 模块**：`import { translate as t } from '.../useLocale'`

---

## 修改原因

V3.4.78 只修了遮罩默认兜底；业务路径 `showLoading('正在…')` 仍主导可见文案，英文体验不完整。

---

## 影响范围

- 前端全局 Loading 与少数相关 toast/叠加层文案
- 无配置 key / 结构树文件增删；无 Git 写操作

---

## 解决方案

| 方案 | 说明 | 选择 |
|---|---|---|
| A. 仅改 GlobalLoading 映射中文字面量 | 脆弱、双语难维护 | 否 |
| B. core `loading.*` + 调用方 t() | 与现有 i18n SSOT 一致，守卫首屏可用 | ✓ |
| C. showLoading 接受 i18n path 内部 t() | 需改 API 与所有调用约定，扩大面 | 未选 |
