## 问题分析（事件逻辑链条）

| 环节 | 内容 |
|------|------|
| 核心症状 | 账号面板头部 `profile-info` 三行白字（昵称 `#fff`、邮箱 `rgba(255,255,255,.82)`、角色徽章白字白描边）与背景同色不可见；这批白字设计上压在头部的品牌渐变横幅上 |
| 根本原因 | V3.4.28 账号中心重设计遗留的玻璃拟态类 `.blur-bg { background: transparent }`（原 1103 行）在**源序上晚于** `.panel-header`（原 1071 行）的品牌渐变声明；两者同为单类选择器特异性 (0,1,0)，同属性按后到者胜出——**头部渐变横幅自 V3.4.28 起即被清空**，白字直接落在白面板上 |
| 为何今日才暴露 | 当日全部会话均为沙盒静态验证（无 vite），本次用户起服务实机回归属首次真实渲染；属 P0-1「实机回归欠账」预期风险的第一个兑现 |
| 受影响的模块 | 仅 `FloatingAccountPanel.vue` 头部横幅。模板另两处引用该类的元素**不受影响**：页脚 `.panel-footer { background:#fff }` 源序（原 1390 行）晚于 `.blur-bg` 而胜出；头像 `.profile-avatar.large` 特异性 (0,2,0) 更高 |
| 候选方案对比 | a) 提升头部选择器特异性（`.panel-header.blur-bg`）——绕过但保留地雷类；b) 移动 `.blur-bg` 规则到渐变之前——同样留雷；c) **删除死类**：规则删除 + 模板 3 处引用摘除——该类现值只有害无用（透明背景对页脚/头像本就不生效），一并消雷。选 c |

## 修改内容

1. `<template>` 3 处 class 摘除：`panel-header blur-bg` / `profile-avatar large blur-bg` / `panel-footer blur-bg` → 去掉 ` blur-bg`（纯 class 属性变更，零结构/逻辑变化）。
2. `<style>` 删除 `.blur-bg { background: transparent }` 规则，原位留注释说明删除原因（防同名类复发）。
3. 全文件 `blur-bg` 引用清零（仅注释中留一处说明性文字）；全项目 grep 确认无其他组件引用该类。

## 修改原因

功能性可视缺陷：用户身份信息（昵称/邮箱/角色）在面板头部完全不可读；且根因属「注册页同 DNA」的品牌渐变横幅整体失效——修复后头部观感才是 V3.4.28 重设计的预期样子（用户此前从未见过正确渲染）。

## 影响范围

- 账号面板头部：渐变横幅**首次点亮**（绿主题绿渐变/蓝主题蓝渐变），白字对比度恢复设计值；经纬网格纹理 `::after` 不受影响（伪元素叠加层）
- 页脚/头像：零变化（见根因分析，两处背景本就不由 .blur-bg 决定）
- 全屏态：头部渐变同样恢复（全屏共用 `.panel-header` 底色，此前同样是白底白字缺陷）
- script/props/事件：零改动

## 解决方案（实施要点）

死类清除（方案 c）：4 处编辑，模板 diff 严格限于 3 个 class 属性；风险面 = 渐变恢复本身，属「回到设计预期」。

## 性能指标
