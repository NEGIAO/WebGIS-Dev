## 修改内容

1. **头部重构**：新增品牌徽标（`fa-earth-asia`）与 CSS 经纬网格纹理（呼应 GIS 主题）；三条功能提示由堆叠长条改为一行胶囊 chip 并配图标，整体高度明显压缩。
2. **模式切换**：登录/注册改为分段式滑块（segmented control），active 态实色 + 投影。
3. **按钮主次分层**：「确认登陆」与「创建账号」升级为实色品牌渐变主按钮；「游客一键登陆」降为描边次按钮；OAuth 按钮统一白底描边 + 品牌色图标（Google 蓝 / GitHub 黑）。
4. **输入控件**：10px 圆角、hover 边框预反馈、聚焦时图标与 label 联动变品牌色（`:focus-within`）、disabled 态灰化。
5. **提示与反馈**：错误/成功提示由纯文字改为带底色描边的横幅；验证码按钮、已验证徽章、头像选择卡片、绑定邮箱告警框全量对齐新风格。
6. **动效收敛**：删除 `.form-group:hover` 整体 translateY 位移（抖动源），保留按钮级细腻反馈；入场动画改缓动曲线。
7. **弹窗与页脚**：密码重置弹窗圆角/头部/关闭按钮翻新；页脚条款链接补充样式。
8. **主题与适配**：全部颜色走 `--brand-primary-rgb` 等主题变量，绿/蓝双主题自动联动；移动端断点同步更新（安全区、单列按钮、验证码换行）。
9. **死代码清理**：移除 scoped 内无效的 `:root` 变量块与模板中不存在的 `.default-login-hint` 规则。

## 修改原因

注册页是平台第一入口，旧样式观感差且主操作不突出（用户反馈"UI 丑"）；借 OAuth 上线契机统一登录入口视觉，降低新用户流失。

## 影响范围

- 前端注册/登录页（含登录、注册、旧账号绑定邮箱、密码重置弹窗四个形态）
- 不影响：鉴权 API、OAuth 回调、路由守卫、游客登陆逻辑、GIS 预热逻辑（script 部分未动一行）
- 无文件增删、无目录调整 → 三个 README 文件树与 `Docs/Guide/project-structure.md`、`frontend-structure.md` 无需变动

## 补记（2026-07-26 19:20 BUG 修复）

用户反馈：切换到注册模式时，变高的表单区遮挡/压缩上方头部卡片。根因：`.form-header` 未设置 `flex-shrink: 0`，容器 `max-height` 约束下 flex 布局压缩了头部（`overflow: hidden` 使其表现为被裁切遮挡）。修复：为 `.form-header` 补充 `flex-shrink: 0`（页脚原本已有），头部高度恒定、表单区独立滚动。已通过 compiler-sfc 编译验证。
