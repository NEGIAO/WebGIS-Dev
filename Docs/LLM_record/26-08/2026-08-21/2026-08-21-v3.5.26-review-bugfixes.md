## 问题分析

### 核心症状

1. SSE 正常连接期间，普通鉴权 API 仍会把用户写入 90 秒兜底心跳集合；关闭页面后连接计数虽被撤销，但心跳记录会让在线人数最多延迟 90 秒下降。
2. ESRI Wayback 目录首次请求失败或后端启动同步尚未完成而返回空数组时，前端仍永久标记为已加载，本组件生命周期内无法重试。
3. Wayback 后端返回带 `+08:00` 的北京时间 ISO 时间，前端转成 UTC 后截日期，凌晨 03:15 同步记录会显示成前一天。
4. CHANGELOG 记录首屏关键瓦片超时为 10 秒，实际代码常量为 15 秒，文档与实现不一致。

### 根本原因

- 在线追踪没有区分“普通鉴权活跃”与“SSE 不可达时显式上报的兜底心跳”；二者都调用 `mark_heartbeat`。
- `historicalCatalogLoaded` 在请求 `finally` 中无条件置真，把失败和暂时空目录误当作完整加载成功。
- 日期格式化使用 `Date.prototype.toISOString()`，隐式把北京时间转换为 UTC。
- 首屏超时调整后未同步更新 CHANGELOG 数值。

### 受影响模块

- 后端实时在线统计 tracker、鉴权活跃记录与 `/statistics/heartbeat`。
- OpenLayers 图层控制面板中的 ESRI Wayback 懒加载目录和更新时间展示。
- V3.5.25/V3.5.26 版本文档、后端结构树与回归测试。

## 候选方案与选型

1. **SSE 断开时无条件清空用户心跳**：可能误删前端已进入降级模式后提交的合法兜底心跳，放弃。
2. **普通鉴权活跃仅在当前无 SSE 连接时刷新心跳；显式 heartbeat 端点始终记录兜底心跳**：既避免健康 SSE 期间产生幽灵记录，也保留断线降级语义，选定。
3. **Wayback 失败后固定间隔自动轮询**：增加后台请求和生命周期复杂度，暂不采用。
4. **仅在获得非空目录时标记加载完成；失败或暂时为空允许用户再次切换页签重试**：改动小且符合懒加载策略，选定。
5. **按浏览器本地时区显示更新时间**：部署用户跨时区时语义不稳定，放弃。
6. **固定按 `Asia/Shanghai` 格式化后端同步时间**：与调度器和后端时间源一致，选定。

## 解决方案

- 为 `OnlineUserTracker` 增加原子的普通鉴权活跃记录方法：持锁检查当前身份是否已有 SSE 连接；有连接则不写兜底集合，无连接才刷新心跳。
- `/statistics/heartbeat` 从 session 提取用户名并显式调用 `mark_heartbeat`，保持降级心跳的独立语义。
- 增加在线 tracker 回归测试，覆盖健康 SSE 期间普通鉴权请求不会造成断开后的 90 秒残留，并覆盖显式兜底心跳仍可保活。
- Wayback 加载完成标记改为仅对非空目录置真；错误和空目录保持可重试。
- 更新时间使用 `Intl.DateTimeFormat` 固定 `Asia/Shanghai` 并由日期部件拼成 `YYYY-MM-DD`。
- 将 CHANGELOG 中首屏超时改为与代码一致的 15 秒，并将版本号推进到 V3.5.26。

## 遗留与风险

- SSE 连接断开的网络层感知时间仍取决于 ASGI/代理何时取消生成器；本次修复针对连接已完成 `drop_connection` 后被普通鉴权心跳继续保活的问题。
- Wayback 空目录采用用户触发重试，没有增加自动轮询；若用户停留在页签内不重新切换，目录不会自行刷新。
