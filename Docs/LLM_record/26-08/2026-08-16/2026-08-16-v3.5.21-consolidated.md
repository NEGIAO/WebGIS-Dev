## 问题分析

### 核心症状（按功能域）

1. **管理面板「数据管理」**：固定仅加载 30 行，无分页、无总数；搜索/排序只在「已加载页」内生效，与全表语义不符；管理员无法浏览/导出整表（用户会话、消息表动辄数百上千行）。
2. **Agent 底图能力**：`switch_basemap` 仅接受 38 项手写白名单 presetId，禁止一切 URL；用户说「换暗色地图/卫星图」但目录内没有合适预设时 Agent 无能为力；白名单与 `basemapPresets.ts` 实际目录（76 项）长期漂移，新增底图需两处维护。
3. **底图目录缺口**：无骑行风格瓦片源（CyclOSM 为 OSM 社区免费无密钥源）。
4. **图标规范盲区**：`LandingView.vue` / `RegisterView.vue` 仍残留大量 FontAwesome 图标与 emoji 前缀（`✅`），违反本仓库「图标统一 Lucide」规范；Google One Tap 因 GSI 脚本异步慢载存在静默失效。

### 根本原因

1. 后端 `list_table_rows` 只返回 `rows` 不含 `total`；前端 `tableOffset` 有状态无 UI；过滤/排序为纯前端 computed，仅作用于当前页。
2. Agent 工具 schema 将 `presetId` 定为唯一参数且提示词「绝不生成 URL」，能力一刀切；预设目录手写在 `agentMapPresets.js`，与 SSOT（`basemapPresets.ts`）脱节。
3. `basemapConfig.ts` / `basemapPresets.ts` 未收录 CyclOSM。
4. 两个视图未参与 V3.5.18 的 Lucide 迁移；`initGoogleOneTap` 在 `onMounted` 同步检查 `window.google`，GSI 未就绪即放弃。

### 受影响模块

管理面板（后端 admin API + 前端组件 + i18n）· Agent 工具链（schema / adapters / presets / 回显）· 底图目录（OL 图源定义 + 预设注册）· Landing/注册页（图标 + OneTap 时序）· 根 `.env`（OAuth Client ID 分级调整）。

## 修改内容

### 一、管理面板数据表格增强（后端 `backend/api/admin.py` + 前端 `AdminControlPanel.vue`）

1. **分页与总数**：`GET /api/admin/db/table/{table}/rows` 响应 `data` 由 `rows: [...]` 扩展为 `{ rows: [...], total: N }`（`COUNT(*)` 与 SELECT 共用 WHERE）；前端新增「上一页 / 第 x / y 页 / 下一页」+ page size（30/100/200/全部，「全部」由前端 200 行/次循环拉取合并）。
2. **跨页搜索**：rows 接口新增 `search` 参数——全列 `LIKE ? ESCAPE '\'` 过滤（`%`/`_`/`\` 转义，参数化防注入）；前端 300ms 防抖 → 回第 1 页重查；导出携带搜索词。
3. **跨页排序**：新增 `sort_key` / `sort_dir`——列名必须命中 `PRAGMA table_info` 真实列集合（白名单，ORDER BY 无法参数化绑定列名），方向仅 asc/desc 字面量，未命中回退 `rowid DESC`；切表自动重置排序。
4. **加载竞态**：请求序号 `rowRequestSeq` 自增捕获、响应比对，过期响应（快速翻页/搜索防抖期间）静默丢弃。
5. **行号列 + 浏览区间信息条**：首列 `#` 为结果集连续序号（`(页码-1)*页大小 + index + 1`）；sticky 信息条显示「第 X-Y 行 / 共 N 行」；行展开编辑模式保留行号列。
6. **搜索命中高亮**：`highlightCell` 先整体 HTML 实体转义（防 XSS）再按命中区间包 `<mark class="search-hit">`，大小写不敏感、多段命中；命中整行弱高亮（`row-hit`）。
7. **CSV 全量导出**：循环拉全量（携带搜索/排序）→ CSV（UTF-8 BOM，Excel 友好，对象 JSON 序列化、引号转义）→ Blob 下载。

### 二、Agent 底图能力开放（`agentToolsSchema.js` / `mapCommandAdapters.js` / `agentMapPresets.js` / `HomeView.vue` / 回显两处）

1. **url 通道（L3 方案，经用户批准）**：`switch_basemap` 参数扩展为 `presetId | url` 二选一——url 复用 `normalizeCustomXyzUrl` 校验（强制 `{z}/{x}/{y}`、协议仅 http/https，token 类 query 参数允许但提示词警示私有密钥可见性）；`HomeView.vue` 的 `setBasemap` 分流：url → OL `setCustomBasemapByUrl` / Cesium `handleCustomBasemapSubmit`（既有 custom 注入链，零新增注入逻辑）。
2. **自主构造公开源**：系统提示词授权「用户未提供 URL 时按意图自行构造公开免密钥 XYZ」，附参考源（OSM / Esri World Imagery & Topo 含 `{z}/{y}/{x}` 倒序提示 / CARTO / OpenTopoMap）与「失败换源重试」指导。
3. **预设目录全量动态派生（L3 方案，经用户批准）**：废除 38 项手写白名单，`AGENT_BASEMAP_PRESETS` 改为从 `BASEMAP_PRESETS`（76 项）全量派生，无黑名单；新增 `formatAgentBasemapPresetCatalog()` 按 id 语义分组（天地图/图新/Google/高德/腾讯/Mapbox/Yandex/MapTiler/ESRI/OSM 系/GeoQ/地形/程序槽位/本地瓦片）；新增底图零维护自动同步。token 类密钥仍由运行时注入，Agent 只见 presetId。
4. **回显适配**：`useAgentMapContext.js` / `chatIntentFallback.js` 的 `switch_basemap` 摘要支持 url 显示（HTML 转义）。

### 三、CyclOSM 骑行底图（`basemapConfig.ts` + `basemapPresets.ts`）

新增 `vector_cyclosm` 图源（`https://{a-c}.tile-cyclosm.openstreetmap.fr/cyclosm/{z}/{x}/{y}.png`，xyz + `prioritizeTileSourceRequest`）与 `vector_cyclosm_preset` 预设；Cesium 侧复用通用 xyz 分支（`{a-c}` 子域自动展开）；Agent 目录经动态派生自动收录。

### 四、Landing / 注册页 Lucide 迁移与 OneTap 修复（`LandingView.vue` / `RegisterView.vue`）

1. 两文件全部 FontAwesome 图标迁移 `@lucide/vue`（LandingView 26 处 / RegisterView 30 处，含三态图标与 `Loader2` + 自建 `spin` keyframes 旋转态）；品牌图标（Google/GitHub/VueJS/Docker）Lucide 无对应，保留 FontAwesome（已批准例外）；清除 `✅` emoji 前缀。
2. Landing CTA 新增登录方式 pill 罗列（Google / GitHub / 邮箱 / 游客，`landing.ctaMethods` 等双语键）；Hero 统计「20+ 底图」→「70+」（与全量目录一致，README/`core.js` 同步）。
3. `initGoogleOneTap` 改 async：新增 `waitForGsi()`（200ms 轮询、5s 超时）等待 GSI 就绪后再 initialize + prompt，修复脚本慢载时 OneTap 静默失效。

### 五、根 `.env` OAuth Client ID 分级调整

`GOOGLE_OAUTH_CLIENT_ID`（后端用）清空——生产值改由 HF Secrets 注入，不再入仓；`VITE_GOOGLE_OAUTH_CLIENT_ID`（前端构建用，L1 公开）更新为新 App 的 ID。两个 key 均已登记 `.env.example`（158/205 行）与 `backend/config/catalog.py`（582 行起），无新增 key。

## 修改原因

管理面板原有 30 行截断无法满足管理员浏览整表的核心诉求（分页 + 搜索 + 导出为主线方案，SQL dump 记入 TODO）；Agent 底图一刀切禁 URL 使其在目录外需求上「有能力却不能做」；白名单双维护违反 SSOT 原则；图标规范需收掉最后盲区；OAuth 生产密钥入仓违反密钥分级。

## 解决方案要点与模块关系

```mermaid
flowchart LR
  subgraph AdminDB[管理面板数据链]
    UI[AdminControlPanel.vue<br/>分页/搜索/排序/高亮/CSV] -->|"limit,offset,search,<br/>sort_key,sort_dir"| API["GET /api/admin/db/table/{t}/rows"]
    API --> Sync["_list_table_rows_sync<br/>列白名单 + LIKE 转义 + COUNT"]
    Sync -->[(SQLite)]
  end
  subgraph AgentBM[Agent 底图链]
    Schema["agentToolsSchema.js<br/>presetId | url 二选一"] --> Adapters["mapCommandAdapters.js<br/>validateBasemapArg"]
    Adapters -->|presetId| Presets["agentMapPresets.js<br/>← BASEMAP_PRESETS 全量派生"]
    Adapters -->|url| Home["HomeView.vue setBasemap 分流<br/>OL setCustomBasemapByUrl /<br/>Cesium handleCustomBasemapSubmit"]
    Presets --> BP["basemapPresets.ts (SSOT)<br/>+ vector_cyclosm_preset"]
    BP --> BC["basemapConfig.ts<br/>vector_cyclosm 图源"]
  end
```

选型理由：分页选「后端返回 total」（契约最小扩展，`COUNT(*)` 无 WHERE 开销极小）；排序选「PRAGMA 列白名单」（ORDER BY 列名无法参数化）；导出选前端 CSV 而非后端 SQL dump（避免与 SQLite 方言耦合）；Agent 目录选全量派生（用户裁决：无黑名单，零漂移）。

## 遗留与风险

- **SQL dump 导出未实现**：已记入 `Docs/TODO/bugfix-optimization-plan.md`，待用户决策是否立项。
- **Agent url 通道 token 可见性（用户已接受）**：URL 中的 key 会进入 LLM 上下文与聊天记录，提示词已警示。
- **全量目录开放**：LLM 可能选中受限源（Google 原版需代理、Mapbox 需密钥）→ 结构化错误 + 换源指导兜底；提示词增大约 3KB/请求。
- **Cesium `handleCustomBasemapSubmit` 返回 void**：注入失败无法反馈给 adapter（校验同源，概率极低）。
- **第三方源无 SLA**：CyclOSM / OSM / OpenTopoMap 社区源可能限流，URL 变更需同步 `basemapConfig.ts` 两处定义。
- **品牌图标 9 处保留 FontAwesome**（Lucide 无品牌 logo，已批准例外）。
- **后端部署依赖**：`GOOGLE_OAUTH_CLIENT_ID` 生产值必须配置到 HF Secrets，否则 Google OAuth 后端流程失效。
